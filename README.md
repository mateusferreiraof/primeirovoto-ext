# Primeiro Voto

> **Educação eleitoral para jovens que estão chegando ao seu primeiro voto.**

O **Primeiro Voto** é um site educacional desenvolvido para ajudar jovens eleitores a conhecerem melhor o processo eleitoral brasileiro de forma **simples, clara e acessível**.

A plataforma apresenta informações importantes para quem está tendo o primeiro contato com o processo de votação, utilizando uma abordagem visual e interativa para facilitar o aprendizado.

---

## Objetivo

O projeto tem como principal objetivo **promover a educação eleitoral entre jovens**, facilitando o acesso a informações essenciais para o exercício consciente do voto.

Entre os conteúdos abordados estão:

* Processo de votação;
* Cargos políticos;
* Local de votação;
* Justificativa eleitoral;
* Quiz sobre conhecimentos eleitorais.

---

## Público-alvo

O site é voltado principalmente para **jovens de 16 a 18 anos** que estão se preparando para votar pela primeira vez.

---

## Funcionalidades

### Conteúdo educativo

Apresentação de informações relacionadas ao processo eleitoral de maneira simples e objetiva.

### Como funciona a votação

Explicações sobre as principais etapas e procedimentos envolvidos no momento da votação.

### Cargos políticos

Informações sobre os cargos escolhidos pelos eleitores e suas respectivas funções.

### Local de votação

Orientações para ajudar o eleitor a encontrar e consultar seu local de votação.

###  Justificativa eleitoral

Informações sobre a justificativa de ausência às urnas.

###  Quiz

Questionário para testar os conhecimentos adquiridos durante a navegação pelo site.

## Como executar

Por ser um projeto desenvolvido apenas com **HTML e CSS**, não é necessário instalar dependências ou configurar um servidor.

### 1. Clone o repositório

```bash
git clone https://github.com/mateusferreiraof/primeirovoto-ext.git
```

### 2. Entre na pasta

```bash
cd primeirovoto-ext
```

### 3. Abra o projeto

Abra o arquivo:

```text
welcome.html
```

diretamente no navegador.
